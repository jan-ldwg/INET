# Helpful commands

|                                 |                                            |
| ------------------------------- | ------------------------------------------ |
| `sudo ip netns`                 | Show all network namespaces                |
| `sudo ip netns exec <ns> <cmd>` | Execute a command in a network namespace   |
| `ip -br a`                      | Shows brief information for all interfaces |
| `ip link set dev <if> up`       | Enables an interface                       |
